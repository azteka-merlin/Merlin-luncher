# Context - Merlin Launcher

Merlin Launcher is the Electron desktop app used by end users. It integrates Steam/SteamDB browsing, manifest/Lua installation, catalog search, fixes, premium games, polls, updates, and native OpenSteamTool components.

## Stack

- Electron 33
- Node.js
- JavaScript
- electron-builder
- C++/CMake for `OpenSteamTool`
- Native Node test runner (`node --test`)

## Main Structure

- `main.js`: Electron main process, service initialization, and IPC registration.
- `preload.js`: safe bridge between renderer and main process.
- `renderer.js`: main existing interface flow.
- `index.html` and `styles.css`: base UI.
- `src/main/`: config, Steam, network, games, premium, updates, polls, auth, library, and IPC services.
- `src/renderer/`: feature-specific UI modules.
- `OpenSteamTool/`: native C++ component and CMake build.
- `assets/dlls/`: DLLs packaged with the app.
- `assets/merlin/merlin-helper.dll`: helper used by the app.
- `scripts/`: doctor, build hooks, NSIS installer script, and metadata tooling.
- `test/`: contract, service, and regression tests.

## Merlin API Integration

Defaults:

- Base API: `https://api-merlin.com/api`
- Manifests: `${MERLIN_API_BASE_URL}/manifests`
- Updates: `https://api-merlin.com/api/updates/latest` and `/api/updates/download`
- Fixes: `https://api-merlin.com/api/fixes/catalog`
- Premium: `https://api-merlin.com/api/premium/catalog`
- Polls: `https://api-merlin.com/api/polls/active`
- Game search: `https://api-merlin.com/api/games/search`

For development, `MERLIN_API_BASE_URL` can point the app at another API. `npm run start:stage` sets it to `https://staging.api-merlin.com/api`; `npm start` keeps the production default.

## App Workflows

- Auth/license: validates a license through the API and stores an encrypted local session.
- Steam: detects Steam, closes/restarts it when needed, and installs files in the right destinations.
- Manifests/Lua: downloads through the API, transforms Lua when needed, and installs files.
- Library: syncs catalog data and resolves game names.
- Fixes/corrections: downloads the catalog and applies compatible fixes.
- Premium: lists games, activates, downloads, and reports progress.
- Updates: checks latest version, downloads installer, and opens the file/folder.
- Polls: fetches active poll and sends votes.

## Native Build

The launcher build depends on DLLs generated by `OpenSteamTool`:

- `OpenSteamTool.dll`
- `dwmapi.dll`
- `xinput1_4.dll`
- `merlin-helper.dll`

`build.js` coordinates native build, copies DLLs to `assets/dlls`, and packages Electron.

## Tests

`npm test` runs tests with `node --test`.

Covered areas:

- IPC contracts
- auth session
- game download/install
- Steam parsers
- catalogs
- Lua transformer
- manifest references
- DLL installer

## Notes

- Do not commit `dist/` or `node_modules/`.
- Be careful when changing IPC: renderer, preload, and contract tests must stay aligned.
- Be careful with Steam paths, DLLs, and install file paths; those affect the user's machine directly.
- Run `npm run release:local` before publishing an update.
- `package.json` version is used by update checks and release flow.
